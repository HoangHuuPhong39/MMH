# Hệ Thống Ôn Thi & Trắc Nghiệm Nhập Môn Mật Mã Học (NMMMH)

Ứng dụng web ôn tập trắc nghiệm và thi thử môn **Nhập môn Mật mã học (NMMMH)** được tối ưu hóa cho cả Máy tính và Điện thoại di động (Responsive UI).

## 🌟 Tính Năng
- **Ngân hàng 132 câu hỏi độc bản chuẩn xác 100%**: Đã được giải và kiểm chứng toán học, kèm lời giải chi tiết và hình ảnh minh họa trích xuất từ đề thi chính thức.
- **Tách riêng 2 bài luyện tập chuyên sâu**:
  - Bài Luyện 1: Lý Thuyết (80 câu).
  - Bài Luyện 2: Bài Tập Tính Toán (52 câu).
- **Cẩm nang lý thuyết & công thức 5 chương**: Bám sát slide môn học, có ô tìm kiếm và cảnh báo bẫy trắc nghiệm.
- **Phòng thi thử bấm giờ đa chế độ**: Đề tổng hợp 40 câu ngẫu nhiên hoặc thi theo từng bộ đề.
- **Sổ tay ghi nhớ câu hay sai**: Tự động lưu lại các câu trả lời sai để luyện tập lại.
- **Giao diện hiện đại**: Hỗ trợ Dark/Light mode, hiệu ứng âm thanh và phím tắt chuyển câu (1, 2, 3, 4 hoặc A, B, C, D).

## 📱 Học Trên Điện Thoại Qua GitHub Pages
Dự án được xây dựng 100% bằng HTML5, CSS3 và Vanilla JavaScript (không cần backend), có thể chạy trực tiếp trên GitHub Pages:
1. Fork hoặc Push repository này lên GitHub của bạn.
2. Vào **Settings** -> **Pages**.
3. Tại mục **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`, nhấn **Save**.
4. Truy cập đường link được cung cấp (dạng `https://<ten-tai-khoan>.github.io/<ten-repo>/`) bằng trình duyệt trên điện thoại.
5. Trên điện thoại, chọn **"Thêm vào Màn hình chính" (Add to Home Screen)** để sử dụng như một ứng dụng di động độc lập!
